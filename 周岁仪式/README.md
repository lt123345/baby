# 宝宝周岁仪式

在线页面：https://baby-first-birthday-ceremony-lt.stirringbluff3.chatgpt.site/

入口为 `dist/index.html`，可直接用浏览器打开；保持 `dist/photos/` 与页面的相对位置即可离线使用。字体已嵌入页面，照片为 WebP，字体许可证附在 `dist/` 中。

页面包括开场、八张照片轮播相册和六项仪式。相册每张停留 6 秒，提供进度条、暂停、手动切换和放大查看。左右键切换仪式，F 全屏，H 隐藏操作栏。

`.openai/hosting.json` 保存现有 Sites 项目标识。GitHub 中的本目录用于保存完整源码与素材；提交到本仓库不会自动发布到 Sites，线上更新仍需走 Sites 发布流程。
