### 夜间（5-20 夜 → 5-21 凌晨）

- **长期背景**：4 点后每小时醒已是**长期模式**，时间久远不可考，**早于辅食开始（5-19）**，与辅食无关
- **本次新出现"拧 → 升级"模式**：
  - 1 点喂奶
  - 之后某次醒来，爸爸抱哄
  - 开始能安静趴在身上 → 过一会儿开始拧 → 逐渐升级
  - 换横抱 → 着急
  - 抱或放都升级 → 最终完全醒
- **排除原因**：
  - 不是饿：1 点刚吃过，且 6:35 早奶只吃 105ml，反向印证
  - 不是辅食：模式早于辅食引入
- **推测机制**：
  - 5-18 刚学会爬，运动皮层处于高活跃状态
  - 睡眠周期切换时短暂浅醒，想找体位/释放运动能量
  - 被抱住限制了动作 → 越抱越憋 → 升级
  - 这是"**睡眠衔接 + 运动能量释放**"问题，不是哄睡技术问题
- **白噪音使用策略**（待验证）：
  - 反应式（升级后才开）效果差：皮质醇已上来，单靠声音难拉回

  - **工具**：手机白噪音 app 或专用白噪音机，50-60 分贝，距床头 ≥ 1.5 米；推荐"吹风机"频谱（粉红噪音，今日爷爷哄睡已验证对本宝宝有效）
  - **不用抽油烟机**：距离远、频谱不合适、操作不现实
- **下次"拧 → 升级"应对（反直觉试点）**：
  1. **把他放下，不要继续抱**
  2. 放进婴儿床让他自由扭、撑、翻（醒着监护安全）
  3. 旁边坐着，低声"嗯嗯" + 白噪音
  4. 让他**自己消耗完运动能量**，观察是否能自行入睡
  5. 若完全失控再回去抱
- **长期判断**：
  - 这条路径如果有效，**正好顺势对接"能不抱就不抱"宗旨**——不是剥夺，是顺应他爬期的发育需求
  - 当前阶段运动需求可能 > 拥抱需求

### 下午觉 救援小觉成功（户外）

- **环境**：刚下完雨，17-19℃，空气质量优，阴天
- **方法**：
  1. 推车出门
  2. **横抱走一圈**
  3. **竖抱走一圈**
  4. 没有任何"哄"的动作，纯走

- **从启动到睡着用时**：极短（远低于室内动辄 30-40 分钟的哄睡）
- **关键洞察**：
  - **户外环境本身就是哄睡工具**：移动 + 柔和视觉 + 户外白噪音（车流/风/鸟）+ 体感温度变化，多通道同时降级，效果碾压室内单点干预
  - **不做主动哄睡反而成功**：印证"他抗拒的不是睡，是被哄睡"。撤掉哄睡仪式，他自己就睡了
  - **横抱→竖抱切换不闹**：说明室内的"姿势对抗"主要是对**特定哄睡情境**的对抗，不是对姿势本身的偏好
  - **户外仍是当前最可靠的哄睡兜底**，推车在室内无效但户外有效，差异在"是否处于哄睡情境"
- **下次试点**：
  - 哄睡失败 ≥ 20 分钟时，**直接转户外**，不要在室内死磕
  - 户外救援小觉的预期定位：可作为白天哄睡 plan B，不必视为偏离

### 夜觉 自主入睡（里程碑）

- **背景**：白天哄睡持续失败 + 旧"温和强硬摆姿势"方法已失效，启用新方案
- **环境准备**：关大灯留暗黄夜灯 → 一关灯**立刻疯狂揉眉毛**（强困意信号）
- **哄睡总耗时**：约 40 分钟
- **流程**：
  1. **L1-L4 渐进**：竖抱重心倒换 → 慢走 → 横抱试一次 → 卧室外溜达 → 均未睡
  2. **L5 妈妈在场**：妈妈躺床，娃放妈妈旁边，爸爸床边轻拍屁股
  3. 娃**自己翻身趴过去**，头埋着用拳头疯狂揉眉毛
  4. 蛄蛹很久，未睡过去，开始哭 → 抱起走动 → 安静
  5. **去楼道慢走几圈** → 趴肩安静几分钟 → 又开始扭闹
  6. 带回屋，**放床垫上**，他又自己蛄蛹
  7. **关键介入**：爸爸用手**轻推几下屁股** → 安静 → 蛄蛹几次后**自己睡过去**
  8. 蛄蛹再起，再轻推屁股 → 睡回去（循环数次后稳定深睡）
- **结果**：**自主入睡成功**（最小辅助：轻推屁股桥接觉醒间隙）
- **关键洞察**：
  - **这是首次接近真正的"自主入睡"**：娃在床垫上而非怀里完成最后入睡
  - **"轻推屁股"≪ 抱睡晃睡**，是把哄睡仪式精简到最小桥接动作的范式
  - **蛄蛹 → 推屁股 → 入睡** 的微循环可能成为新的哄睡范式
  - **关灯立刻揉眉毛**：环境信号已建立条件反射，说明降级仪式已经在起作用
  - **楼道走动作为中段降级**有效，比室内走动更新鲜
- **与今日下午对比**：
  - 下午困过头 → 应激模式 → 所有方法失效
  - 夜觉清醒窗口控制得当 + 出牙不适已被磨牙棒部分释放 → 同样的"陪伴+最小介入"模式就有效
  - 印证：**方法有效的前提是娃处于可调节的生理状态**，方法本身不是万能钥匙
- **下次复制要点**：
  - 关灯仪式作为启动信号继续保留
  - 优先放床垫，不优先怀抱
  - 轻推屁股作为最小桥接动作，**避免回到抱睡晃睡**
  - 妈妈在场的"陪伴"是关键变量，不必抱
  - 接受 30-40 分钟总耗时，不焦虑长度

- **处理**：换尿布，几乎没哄

### 夜醒 2（约 4:40）— 1 小时复刻日间自主入睡

- **触发**：自己醒，翻身趴起来
- **流程**：
  1. 爸爸故意不管，让他自己活动
  2. 活动一会儿后**又开始揉眉毛找姿势**（困意再起）
  3. 自己蛄蛹约 30 分钟，未睡过去 → 哭
  4. 抱起蹲一会儿 → 安静
  5. 撑起半身（可能爸爸体温过高）→ 放下 → 蛄蛹 → 哭
  6. 再抱 → 安静 → 放下 + **推屁股** → 睡回去
- **总耗时**：约 1 小时
- **结果**：再次自主入睡，方法与日间夜觉一致
- **关键洞察**：
  - **日间建立的"推屁股桥接"技能在夜醒场景同样有效** → 模式可跨场景迁移
  - **30 分钟独立尝试可能偏长**：5-6 月龄夜醒中后段（4 点后）皮质醇已开始上升，独立尝试上限建议 **15-20 分钟**
  - **"撑起半身 + 不舒服"**可能是温度信号：与爸爸同床，爸爸体温会持续传热；下次尝试**降低同床覆盖物**或**侧身远一点**
  - **抱起蹲 → 放下** 这个轻量节奏比"抱起来回踱步"更克制，值得保留
- **下次复制要点**：
  - 夜醒后**先观察 2-3 分钟**，不要立刻换尿布或介入
  - 独立尝试给 15-20 分钟上限，超时及时切到"抱起短暂安抚 → 放下 + 推屁股"
  - 控制同床传热，必要时拉开物理距离
