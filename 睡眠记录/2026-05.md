### 夜觉 自主入睡（里程碑）

- **背景**：白天哄睡持续失败 + 旧"温和强硬摆姿势"方法已失效，启用新方案
- **环境准备**：关大灯留暗黄夜灯 → 一关灯**立刻疯狂揉眉毛**（强困意信号）
- **哄睡总耗时**：约 40 分钟
- **流程**：
  1. **L1-L4 渐进**：竖抱重心倒换 → 慢走 → 横抱试一次 → 卧室外溜达 → 均未睡
  2. **L5 妈妈在场**：妈妈躺床，娃放妈妈旁边，爸爸床边轻拍屁股
  3. 娃**自己翻身趴过去**，头埋着用拳头疯狂揉眉毛
  4. 蛄蛹很久，未睡过去，开始哭 → 抱起走动 → 安静
  5. **去楼道慢走几圈** → 趴肩安静几分钟 → 又开始扭闹
  6. 带回屋，**放床垫上**，他又自己蛄蛹
  7. **关键介入**：爸爸用手**轻推几下屁股** → 安静 → 蛄蛹几次后**自己睡过去**
  8. 蛄蛹再起，再轻推屁股 → 睡回去（循环数次后稳定深睡）
- **结果**：**自主入睡成功**（最小辅助：轻推屁股桥接觉醒间隙）
- **关键洞察**：
  - **这是首次接近真正的"自主入睡"**：娃在床垫上而非怀里完成最后入睡
  - **"轻推屁股"≪ 抱睡晃睡**，是把哄睡仪式精简到最小桥接动作的范式
  - **蛄蛹 → 推屁股 → 入睡** 的微循环可能成为新的哄睡范式
  - **关灯立刻揉眉毛**：环境信号已建立条件反射，说明降级仪式已经在起作用
  - **楼道走动作为中段降级**有效，比室内走动更新鲜
- **与今日下午对比**：
  - 下午困过头 → 应激模式 → 所有方法失效
  - 夜觉清醒窗口控制得当 + 出牙不适已被磨牙棒部分释放 → 同样的"陪伴+最小介入"模式就有效
  - 印证：**方法有效的前提是娃处于可调节的生理状态**，方法本身不是万能钥匙
- **下次复制要点**：
  - 关灯仪式作为启动信号继续保留
  - 优先放床垫，不优先怀抱
  - 轻推屁股作为最小桥接动作，**避免回到抱睡晃睡**
  - 妈妈在场的"陪伴"是关键变量，不必抱
  - 接受 30-40 分钟总耗时，不焦虑长度

### 夜醒 2（约 4:40）— 1 小时复刻日间自主入睡

- **触发**：自己醒，翻身趴起来
- **流程**：
  1. 爸爸故意不管，让他自己活动
  2. 活动一会儿后**又开始揉眉毛找姿势**（困意再起）
  3. 自己蛄蛹约 30 分钟，未睡过去 → 哭
  4. 抱起蹲一会儿 → 安静
  5. 撑起半身（可能爸爸体温过高）→ 放下 → 蛄蛹 → 哭
  6. 再抱 → 安静 → 放下 + **推屁股** → 睡回去

- **结果**：再次自主入睡，方法与日间夜觉一致

  - **日间建立的"推屁股桥接"技能在夜醒场景同样有效** → 模式可跨场景迁移

- **下次复制要点**：
  - 夜醒后**先观察 2-3 分钟**，不要立刻换尿布或介入
  - 独立尝试给 15-20 分钟上限，超时及时切到"抱起短暂安抚 → 放下 + 推屁股"
  - 控制同床传热，必要时拉开物理距离
