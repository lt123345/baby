- **推测**：5-18 学会爬，运动皮层高活跃；睡眠周期切换时浅醒，想找体位/释放运动能量；抱住限制动作 → 越抱越憋 → 升级。这是**睡眠衔接 + 运动能量释放**问题，不是哄睡技术
- **白噪音策略**（待验证）：
  - 反应式（升级后才开）效果差
  - **预防式**：约 3:30 开始全程白噪音到 7 点，覆盖每小时醒窗口
  - 工具：手机或专用机，50-60 分贝，距床头 ≥ 1.5m；"吹风机"频谱（粉红噪音，今日爷爷哄睡已验证有效）
  - 不用抽油烟机
- **下次"拧→升级"试点**：
  1. 放下不抱
  2. 进婴儿床自由扭/撑/翻（监护安全）
  3. 旁边低声嗯嗯 + 白噪音
  4. 让他自己消耗完，看能否自行入睡
  5. 完全失控再抱
- **长期判断**：路径有效 = 顺势对接"能不抱就不抱"。当前运动需求可能 > 拥抱需求

### 上午第三觉 哄睡失败

- **偏离**：抱睡（横抱晃睡），违背"能不抱"

- **过渡**：抱晃 → 抱不晃 → 床上轻拍 → 床上陪伴 → 自主入睡，目前不强求

### 当日总结

### 夜觉 自主入睡（里程碑）

- **背景**：白天持续失败 + 旧方法失效，启用新方案
- **环境**：关大灯留暗黄夜灯 → 一关灯**立刻疯狂揉眉**（强困意）
- **耗时**：约 40 分钟
- **流程**：
  1. **L1-L4 渐进**：竖抱重心倒换 → 慢走 → 横抱试一次 → 卧室外溜达 → 均未睡
  2. **L5 妈妈在场**：妈妈躺床，娃放旁边，爸爸床边轻拍屁股
  3. 娃**自己翻身趴过去**，头埋着用拳头疯狂揉眉
  4. 蛄蛹很久未睡，开始哭 → 抱起走动 → 安静
  5. **去楼道慢走几圈** → 趴肩安静几分钟 → 又扭闹
  6. 回屋**放床垫**，又自己蛄蛹
  7. **关键介入**：爸爸**轻推几下屁股** → 安静 → 蛄蛹几次后**自己睡过去**
  8. 蛄蛹再起，再轻推 → 睡回去（循环数次后稳定深睡）
- **结果**：**自主入睡**（最小辅助：轻推屁股桥接觉醒间隙）
- **洞察**：
  - **首次接近真正自主入睡**：在床垫而非怀里完成最后入睡
  - **轻推屁股 ≪ 抱睡晃睡**，最小桥接动作范式
  - **蛄蛹 → 推屁股 → 入睡** 微循环可能成新范式
  - 关灯立刻揉眉 = 环境信号已建立条件反射
  - 楼道走动作为中段降级有效
- **与下午对比**：
  - 下午困过头 → 应激 → 所有方法失效
  - 夜觉窗口控制好 + 磨牙棒部分释放出牙 → 同样"陪伴+最小介入"就有效
  - **方法有效的前提是娃处于可调节的生理状态**
- **复制要点**：关灯仪式继续；优先床垫；轻推屁股最小桥接；妈妈陪伴关键；接受 30-40 分钟

### 夜醒 2（约 4:40）— 1 小时复刻日间自主入睡

- **触发**：自己醒，翻身趴起
- **流程**：
  1. 爸爸故意不管，让他活动
  2. 一会儿**又揉眉找姿势**（困意再起）
  3. 自己蛄蛹约 30 分钟未睡 → 哭
  4. 抱起蹲一会 → 安静
  5. 撑起半身（爸爸体温过高？）→ 放下 → 蛄蛹 → 哭
  6. 再抱 → 安静 → 放下 + **推屁股** → 睡
- **总耗时**：约 1 小时
- **结果**：再次自主入睡
- **洞察**：
  - **日间"推屁股桥接"在夜醒同样有效** → 模式可跨场景迁移
  - **30 分钟独立尝试可能偏长**：4 点后皮质醇上升，上限 15-20 分钟
  - **撑起半身** 可能是温度信号：同床传热，下次降低覆盖或拉开距离
  - **抱起蹲 → 放下** 比抱起踱步更克制
- **复制要点**：夜醒先观察 2-3 分钟；独立尝试 15-20 分钟上限；控制同床传热
