## 2026-07-12（232天）

### 夜觉（7-11 夜）：出牙倒退期开始好转

- **前半夜（~12 点前）**：多次蛄蛹两下自己睡回去 —— **自主接觉恢复**，是好转的关键信号
- **12 点–1 点多**：哄不睡的一段。多次抱起 → 走动安静 → 坐下抱着他就开始动；感觉睡熟放下又蛄蛹。**喂奶后再抱、再放下就好**（提示这段有饥饿 / 反流因素叠加，非纯出牙）
- **1 点多–5 点多**：睡得不错
- **6 点多**蛄蛹几下，**7 点醒**
- **对比 7-8/9/10 三夜**：0-2 点、3-6 点每十几分钟蛄蛹的重灾局面明显缓解；前半夜已能自主接觉，后半夜连续睡 4h（1→5 点）
- **归因（推测）**：下牙第三颗今日已冒出（破龈期结束 → 牙龈痛峰值过去），睡眠随之回升。印证 7-11 记录"出牙为主因"的判断。12-1 点那段抱走 + 喂奶才安抚，提示**反流残留**仍是后半夜潜在扰动因素

## 2026-07-11（231天）

### 出牙倒退期观察（近三夜 7-8 / 7-9 / 7-10 夜）

- **现象**：夜间频繁蛄蛹醒。**0-2 点、3 点多到 5-6 点多**为重灾区，每 30min / 十几分钟 / 甚至几分钟蛄蛹一次
- **哄睡回退**：不抱几乎哄不睡；夜里蛄蛹睡不回去需抱，抱到刚安静放下即醒，抱到**呼吸变深**放下十几分钟又蛄蛹
- **伴随**：口水又变多、情绪略暴躁、**下牙第三颗（下侧切牙）显白**
- **归因（推测）**：出牙（下侧切牙破龈期）为主，叠加**大运动爆发**（7-11 扶物站起）+ 可能**反流残留**（后半夜憋气打挺史），三因素同期
- **应对**：
  - 放下判据提高——等呼吸慢而匀 + 头全重 + 肢体全松、**≥3min 深睡**再放（出牙期浅睡窗口更长，"呼吸变深"不够）
  - 睡前冷磨牙棒 / 冷牙胶释放牙龈痛
  - 暂时接受抱睡安抚（生理痛非习惯问题，牙出后再收）
  - 排查太热（同床传热）/ 反流
