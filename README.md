# 宝宝信息库

记录成长信息，便于回顾和 LLM 分析。

## 文件结构

| 路径 | 内容 |
|---|---|
| `宝宝基本信息.md` | 出生信息 + 当前状态快照 |
| `育儿宗旨.md` | 长期原则 |
| `里程碑.md` | 出牙/大运动/语言/疫苗节点 |
| `睡眠记录/YYYY-MM.md` | 月度睡眠日志 |
| `健康记录/` | 疫苗、就诊、用药 |

## LLM 使用指引

**必读**：`宝宝基本信息.md`（月龄、状态）、`育儿宗旨.md`（原则对齐）。

**按问题加读**：
- 睡眠 → `睡眠记录/` 最近 1-2 月
- 发育 → `里程碑.md`
- 健康 → `健康记录/`

**新事件**：主动问是否更新对应文件。睡眠 → 当月文件；发育节点 → 里程碑；状态变化 → 基本信息。

**格式**：
- 睡眠用 `## YYYY-MM-DD（X天）` 标题
- 里程碑每条 `- YYYY-MM-DD` 开头
- 推测/分析标注"推测""观察"
