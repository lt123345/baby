# 宝宝信息库

记录宝宝成长过程中的各类信息，便于回顾和 LLM 辅助分析。

## 文件结构

| 路径 | 内容 | 更新频率 |
|---|---|---|
| `宝宝基本信息.md` | 基础档案：出生信息、当前状态快照 | 偶尔（状态变化时） |
| `育儿宗旨.md` | 长期育儿目标和原则 | 极少（理念变化时） |
| `里程碑.md` | 出牙、大运动、语言、疫苗等发育节点 | 事件发生时 |
| `睡眠记录/YYYY-MM.md` | 月度睡眠日志，记录哄睡过程和规律 | 按需，重要事件必记 |
| `健康记录/` | 疫苗、就诊、用药等健康相关 | 事件发生时 |

## 给 LLM 的使用指引

**回答问题或给建议前必读：**
1. `宝宝基本信息.md` —— 了解当前月龄、体重、发育阶段
2. `育儿宗旨.md` —— 所有建议必须与长期理念对齐

**根据问题类型加读：**
- 睡眠相关 → `睡眠记录/` 最近 1-2 个月文件
- 发育/成长相关 → `里程碑.md`
- 健康相关 → `健康记录/` 对应文件

**记录新事件时：**
- 主动询问用户是否更新对应文件
- 睡眠事件 → 追加到当月 `睡眠记录/YYYY-MM.md`
- 发育节点 → 追加到 `里程碑.md` 对应分类
- 状态快照变化（如出牙数变化） → 同步更新 `宝宝基本信息.md`

**写入格式约定：**
- 睡眠记录用 `## YYYY-MM-DD（X天）` 作为日期标题，方便 grep
- 里程碑按分类组织，每条以 `- YYYY-MM-DD` 开头
- 涉及推测/分析的内容标明"推测"或"观察"，区分事实和判断
