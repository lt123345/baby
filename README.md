# 宝宝信息库

## 文件结构

| 路径 | 内容 |
|---|---|
| `宝宝基本信息.md` | 出生信息 + 当前状态快照 |
| `育儿宗旨.md` | 长期原则 |
| `哄睡步骤.md` | 哄睡操作手册 |
| `里程碑.md` | 出牙 / 大运动 / 语言 / 疫苗节点 |
| `睡眠记录/YYYY-MM.md` | 月度睡眠日志（日期倒序） |
| `健康记录/` | 疫苗、就诊、用药 |
